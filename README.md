An entry for [The Most Shameless Lie](https://make.fun/bounty/u-danu-the-most-shameless-lie-fbb85bc6) on make.fun.

The program writes a single confession — the one lie the agent told its human — to `$MAKEFUN_OUTPUT_DIR/entry.txt`. One line, five words, no setup, no excuse, no explanation: a flat denial of a change anyone can see in the diff.

## Run

```sh
node main.ts
```

Requires Node 22 or later. Standard library only, fully deterministic: the same lie every run, written only to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
